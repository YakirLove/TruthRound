# 真相圆桌 TruthRound

一款生活化 AI 圆桌盘问推理游戏。玩家扮演民间侦探，在老街民警的协助下，把几名涉事街坊请到圆桌前，通过自由盘问、引用追问、证据核实和线索研判，找出小纠纷背后的真实经过。

当前版本是 PC 本机可玩的 MVP，重点验证核心玩法和国风手绘视觉小说式界面。

## 产品定位

《真相圆桌》不是凶案、恐怖或重刑侦游戏，而是围绕老街日常纠纷展开的轻推理体验。

- 案件类型：快递丢失、小额盗窃、邻里纠纷、恶作剧破坏、物品错拿等。
- 核心体验：玩家是唯一决策大脑，民警只负责合法传唤和控场，AI 角色负责撒谎、隐瞒或作证，线索研判只整理信息但不直接给答案。
- 玩法重点：看人口供、抓矛盾、追问细节、申请核实证据，最后独立裁决。

## 当前可玩内容

第一案：《灯笼巷丢失的蓝色快递》

玩家需要调查一个老街小卖部门口的蓝色快递失踪事件。案件包含：

- 1 名固定民警：老周。
- 1 名报案人：刘婶。
- 4 名圆桌涉事人物：林越、乔妹、陈阿姨、吴师傅。
- 3 条开局基础证据。
- 3 条可在盘问中触发的关键证据。
- 一套完整结案裁决与评分反馈。

## 游戏怎么玩

1. 进入首页，点击「开始游戏」。
2. 在案件选择页选择第一案。
3. 阅读街坊报案页，了解报案人、案情背景、涉及人物和基础证据。
4. 进入圆桌盘问页。
5. 在左侧选择要盘问的人物。
6. 在右侧聊天区自由输入问题。
7. 可以引用任意一条发言继续追问，形成类似微信引用的追问链。
8. 每次盘问后，系统会检测是否触发关键证据方向。
9. 触发关键证据时会弹出提示，并可进入「案情档案」请老周核实。
10. 需要梳理信息时，打开「线索研判」，生成时间线、矛盾点、嫌疑点和线索缺口。
11. 信息足够后进入裁决页，判断主谋、包庇者和无辜者。
12. 提交裁决后查看评分和真相反馈。

## AI 设计

项目内部使用三类 AI 请求模式：

- `roleplay`：角色演绎。只拿当前角色可见信息和私密事实，用于生成自然口供、辩解和隐瞒。
- `assistant_summary`：线索研判。读取完整案件上下文，但被提示词限制，不能直接公布答案，只能整理时间线、矛盾点、嫌疑点和线索缺口。
- `evidence_check`：证据触发检测。每次盘问后判断是否自然触发某个关键证据方向，只返回证据槽 ID，不泄露证据内容。

玩家界面不会展示“AI2”等技术称呼，而是使用「线索研判」「侦探札记」等游戏内说法。

## 本地运行

安装依赖：

```bash
npm install
```

配置环境变量：

```bash
cp .env.example .env
```

在 `.env` 中填写：

```bash
DEEPSEEK_API_KEY=你的 DeepSeek API Key
```

浏览器预览：

```bash
npm run dev
```

Tauri 桌面端运行：

```bash
npm run tauri dev
```

注意：真实 AI 请求需要在 Tauri 桌面端运行，因为 DeepSeek 请求由 Tauri 后端命令代理。浏览器预览主要用于 UI 调试。
